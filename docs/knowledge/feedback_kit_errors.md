---

Ошибки при создании комплектов, которые нельзя повторять:

1. **Не разделять общие детали** — если одна деталь используется в нескольких комплектах, нужно разделить stock между ними (как с PERSHULT кронштейнами)

2. **Неправильный stock комплекта** — для зависимых комплектов stock = min(stock детали / qty в комплекте). Для независимых показывать "Комплект"

3. **Несинхронное отображение** — бейдж количества должен быть одинаковым везде: в карточке И в модальном окне

4. **Общая сумма для независимых** — для independent комплектов НЕ показывать "Итого" и цену комплекта, т.к. детали продаются отдельно

5. **Разделять похожие категории** — "Полки для цветов" и "Подставки для растений" это одно и то же, не разделять

**Why:** Эти ошибки путают пользователя и создают несоответствие между UI и реальными данными.

**How to apply:** При создании комплекта проверить тип (dependent/independent), правильно рассчитать/не рассчитывать stock, убедиться что UI синхронизирован.
