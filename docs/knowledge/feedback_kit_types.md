Комплекты IKEA делятся на два типа:

1. **Зависимые комплекты** — детали обязательны для сборки одного товара
   - Примеры: столы (LINNMON/ADILS, LAGKAPTEN/MITTBACK), стулья (ÖRFJÄLL), полки с кронштейнами (BERGSHULT/PERSHULT)
   - Количество = минимум из (stock детали / qty в комплекте)
   - Если не хватает деталей — показывать "Не хватает деталей"

2. **Независимые комплекты** — детали можно комбинировать как угодно
   - Примеры: SKÅDIS (доска + корзины + крючки), BOAXEL (направляющие + полки + корзины)
   - Детали самостоятельные, продаются вместе как демо-набор
   - Показывать бейдж "Комплект" вместо количества

**Why:** Чтобы не путать пользователя неправильным количеством. Независимые комплекты нельзя считать по минимуму — каждая деталь самодостаточна.

**How to apply:** При создании комплекта определять тип. Для независимых устанавливать stock=1 и показывать "Комплект".
