Каталог товаров с фотографиями в PDF (не путать со встроенным `POST /admin/pdf/catalog` — тот делает голую таблицу без картинок и с колонкой «Наличие»).

**Пайплайн:** скрипт тянет товары из Atlas → пишет HTML → `headless Chrome --print-to-pdf`. Тот же подход, что у project_matkasym_etiketki. Puppeteer НЕ установлен, Chrome вызывается напрямую: `--headless=new --no-pdf-header-footer --virtual-time-budget=60000`. Рендерить из scratchpad, вывод в `/private/tmp` (TCC), потом копировать на Desktop.

**Грабли вёрстки под печать в Chrome** (все три ловил на этом каталоге):
1. **CSS Grid игнорирует `break-inside: avoid`** — карточки резались пополам на границе страницы. Лечится `display: flex; flex-wrap: wrap` у контейнера. Бонус: флекс тянет карточки ряда к одной высоте, цены выравниваются.
2. **`break-after: avoid` у заголовка раздела** Chrome понимает как «не отрывать от ВСЕГО следующего блока» — переносил раздел целиком, полстраницы пустовало. Оставлять можно только вместе с п.3.
3. **Дефолтные `orphans/widows: 2`** запрещают оставить на странице один ряд карточек, поэтому раздел из двух рядов уезжал целиком. Ставить `orphans: 1; widows: 1` контейнеру карточек. Это дало −2 страницы.

**Картинки:** Cloudinary-исходники по 5–6 МБ, Chrome не успевает их скачать. Подставлять трансформацию `f_jpg,q_auto:good,w_900,c_limit` после `/image/upload/` (та же идея, что `tgImage()` в `lib/telegram.js`).
