Дизайнер пишет задачу (+скриншоты) → сервер шлёт repository_dispatch `site-change` → `.github/workflows/site-change.yml` запускает Claude Code CLI (модель claude-sonnet-5-5, только Read/Edit/Write/Glob/Grep) в ветке `design/<id>` → `.github/site-change/bot.mjs guard` откатывает всё вне client/src|client/public и api/, context/, roles.js → сборка (одна попытка починки) → PR → Render PR preview `matkasym-site-pr-N.onrender.com` → Telegram владельцу → «Принять» = dispatch `site-change-merge` (squash в main).
