# Грабли сайта
## Каталог, карточки, комплекты

**Новый товар не видно в каталоге**
→ Две независимые причины: без `isOnOrder: true` фронт прячет как «нет в наличии»;
`createdAt` не проставляется при `Product.create` из-за зарезервированного в Mongoose
поля `isNew` → товар уходит в хвост сортировки за пределы первой 1000.
→ Ставить `isOnOrder` и проставлять `createdAt` вручную после вставки. project_matkasym_test_import

**Кроп фотографии «поехал» на сайте**
→ Фронт (`cloudinaryOpt`) вставляет `f_auto,q_auto,w_N` сразу после `/upload/`, resize
применяется ДО crop.
→ URL с crop-трансформом в `images` не хранить: кроп «запекать» в отдельный ассет,
хранить чистый URL. project_matkasym_test_import

**Привозной товар заведён, а поставщика в системе нет**
→ Указали `supplier.company` только в товаре.
→ Сначала запись в коллекции `suppliers`, потом привязка товаров. feedback_suppliers

**У комплекта неправильное количество**
→ Считали по минимуму деталей независимый комплект (SKÅDIS, BOAXEL).
→ Зависимые (стол, стул) — `min(stock детали / qty)`; независимые — бейдж «Комплект»,
`stock=1`, без «Итого» и цены комплекта. feedback_kit_types feedback_kit_errors

**Одна деталь посчиталась дважды**
→ Деталь входит в несколько комплектов, stock не разделили (кейс PERSHULT).
→ Делить остаток общей детали между комплектами; бейдж количества держать одинаковым
в карточке И в модалке. feedback_kit_errors

**Товар из каталога уехал в закуп через тестовую продажу**
→ Считали «есть в каталоге» по факту привязки `product`, а у теста привязана его же
карточка со статусом `test_sale`.
→ Каталогом считать только статус не из `['test_sale','planned','in_development']`
(`isCatalogProduct`). Цена ошибки — 27 лишних заявок. project_matkasym_product_launch

**Матчер связал «для хранения» с «для хранение»**
→ Сравнение по русским словам ловит что угодно.
→ Модель опознавать только по латинским словам каталога + транслитерация + Левенштейн.

## Интерфейс

**Модалка открывается не по центру экрана**
→ `transform` (или `filter`, `perspective`, `will-change`) у ЛЮБОГО предка ломает
`position: fixed`. В `Admin.css` был `animation: … both`, оставлявший `translateY(0)`.
→ Искать transform на предках, а не крутить стили модалки. Не использовать fill-mode
`both`/`forwards` у анимаций-обёрток. Надёжнее всего — `createPortal` в `document.body`.
feedback_modal_positioning

**Магазин снова тянет трёхмегабайтный бандл**
→ Импорты админки вернули в `App.jsx`.
→ Маршруты админки живут в `AdminRoutes.jsx` и грузятся лениво. project_matkasym_tg_shop

## PDF из headless Chrome: на Android нет текста (31.10.2026)
- **Симптом:** каталог ONOY SAKTA на Android (встроенный просмотрщик Xiaomi) — картинки и линии есть, текста нет вообще.
- **Причина:** Google Fonts отдаёт variable-шрифты → Chrome вшивает их в PDF как **Type 3**; многие Android-просмотрщики Type 3 не рисуют. Тот же Type 3 даёт SVG-текст с обводкой (`paint-order: stroke`).
- **Как не повторить:** шрифты — статичные woff2 из `@fontsource` (jsDelivr) через `@font-face`, не `fonts.googleapis.com`; подложку под SVG-текстом делать `<rect>`, не обводкой. Проверка: `pdffonts файл.pdf` — должно быть `CID TrueType`, ни одного `Type 3`. Исправлено 31.10.2026 во всех трёх готовых каталогах: общий модуль server/lib/catalogFonts.js (FONT_CSS + LIGHT_META).

## Каталог с сайта на телефоне выходит чёрным (31.10.2026)
- **Симптом:** PDF, сохранённый с телефона кнопкой «PDF» (генератор catalogPrint.js), — тёмный фон вокруг и под листами, текст тёмный на тёмном.
- **Причина:** авто-тёмная тема Chrome/браузера на Android затемняет страницу печати, хотя в CSS `background:#fff`.
- **Как не повторить:** на всех страницах печати `<meta name="color-scheme" content="only light">` + `color-scheme: only light` в CSS (catalogPrint, kyzmatPrint, servicesPrint, requestsPrint, готовые каталоги).

**02.11.2026 · Сжатие PDF Ghostscript убило фото на iPhone.** Симптом: в Preview/PDFKit пропадают почти все картинки, `CG_PDF_VERBOSE=1` пишет `invalid image ColorSpace`, а poppler показывает нормально. Причина: gs пишет пустой ICC-профиль. Лечится `-sColorConversionStrategy=RGB -dProcessColorModel=/DeviceRGB`. Каталоги для телефонов проверять рендером через PDFKit, не только pdftoppm. Ещё: ключи сетов совпадают у брендов (kooz-koopsuzduk, bekem-fasad есть и в HOME), привязку файла к сету делать с учётом бренда.

**02.11.2026 · Большой PDF без ошибки выходил с пустым хвостом.** Каталог HOME на 116 листов: Chrome headless не догрузил сотни фото за virtual-time-budget, размер варианта плавал (2,3–7 МБ при тех же 116 листах). Признак: разное число картинок у вариантов одного каталога в `pdfimages -list`. Лечится заранее: скачать фото с повторами и печатать из file:// (build-generated-catalog.js, localizeImages).

- **git push на GitHub падает с HTTP 408 / «remote end hung up» (03.11.2026, kyzmat-site, 9 МБ):** причина — медленная/нестабильная отдача с этой сети, а не размер буфера: `http.postBuffer` и HTTP/1.1 не помогают, SSH не настроен (host key). Решение: пушить небольшими коммитами (~1 МБ, по файлу) с повторами; файл на 3 МБ проходит с 2–3 попытки.

**10.11.2026 · Значок CROSS в списке сетов не появился после деплоя.** Причина: в BrandSection (AdminSets.jsx) `setCats` грузится только при `liveSubs` (бренд KYZMAT), а я повесил значок на эти данные. Перед тем как брать готовое состояние компонента, смотреть условие его загрузки. Проверять выкладку на Render по хешу нового чанка `AdminRoutes-*.js` из локального `client/dist`, а не по строке: она могла попасть на сайт ещё с прошлым коммитом.

**14.11.2026 · В PDF сета HOME выходил один цвет из нескольких.** У ENIGMA, INFINITY, FENIX и KERBEN чёрный и белый варианты называются одинаково и различаются только полем `color`. AdminPdfButton выбрасывал «дубли» по одному `name`, поэтому оставался первый цвет. Вдобавок одноцветной карточке подставлялась общая обложка сайта (`__siteCover`) другого цвета: подпись «белый», а на фото чёрная вешалка. Теперь дубль определяется по `name|color`, `mergeHomeVariants` склеивает и одинаково названные цвета, а одноцветная карточка берёт `__ownCover`.
